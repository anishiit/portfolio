## 🛠️ Tech Stack
The portfolio is built with the following technologies:
- **Frontend**:
  - **HTML5**: Structuring the content.
  - **CSS3** & **Tailwind CSS**: For responsive and visually appealing design.
  - **JavaScript**: Adding interactivity and logic.
  - **React.js**: Component-based UI for a smooth and dynamic user experience.

- **Backend**:
  - **Node.js**: JavaScript runtime for server-side processing.
  - **Express.js**: Web framework for handling routing and APIs.

- **Deployment**:
  - **Vercel**: For seamless deployment and continuous integration.

## ✨ Features
- **About Me**: A section introducing myself, my background, and my professional journey.
- **Skills**: Showcasing my technical expertise in various tools, libraries, and frameworks, primarily focused on the MERN stack.
- **Projects**: A detailed display of my best projects with live links and GitHub repositories for each.
- **Contact Me**: An easy-to-use form to get in touch directly, sending queries and project ideas.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Animations**: Subtle animations to enhance user experience without overwhelming the interface.
